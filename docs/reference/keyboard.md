# Keyboard shortcuts

On macOS, `Cmd` replaces `Ctrl` in every shortcut except the four focus shortcuts, which use `Ctrl` on every system.

## Files

| Keys | Action |
| --- | --- |
| `Ctrl+S` | Save in the document's format. |
| `Ctrl+O` | Open a file. |

## Focus

| Keys | Action |
| --- | --- |
| `Ctrl+Shift+1` | Focus on the whole document. Nothing is dimmed. |
| `Ctrl+Shift+2` | Focus on the section. Other sections are dimmed. |
| `Ctrl+Shift+3` | Focus on the paragraph. Other paragraphs are dimmed. |
| `Ctrl+Shift+4` | Focus on the sentence. Other sentences and paragraphs are dimmed. |

## Panels

| Keys | Action |
| --- | --- |
| `Ctrl+.` | Open or close the lens. |
| `Ctrl+\` | Show or hide the map. Leaves focus mode. |
| `Ctrl+Shift+F` | Focus mode: fold away the map and the lens, and fade the top bar until you point at it. The lens can still be opened for a look. |
| `Esc` | Close the lens. |

## Editing

| Keys | Action |
| --- | --- |
| `Ctrl+B` | Bold. |
| `Ctrl+I` | Italic. |
| `Ctrl+K` | Add, change or remove a link. |
| `Ctrl+Z` | Undo. Applying a suggestion is undoable. |
| `Ctrl` + click on a link | Open the link in a new tab. |

## Typed shortcuts

Type these at the start of a paragraph, followed by a space.

| Type | Result |
| --- | --- |
| `# ` | Heading 1 |
| `## ` | Heading 2 |
| `### ` | Heading 3 |
| `- ` or `* ` | Bulleted list |
| `1. ` or `1) ` | Numbered list |
